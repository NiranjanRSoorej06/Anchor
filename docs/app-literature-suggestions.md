# App Literature: Authors' Own Suggestions (2026-09-05)

What PTSD-app papers themselves recommend (Discussion/Future-directions),
plus other PTSD app trials. Full-text sources unless marked abstract-only.

## Per-paper suggestions
- **Owen 2015** (mHealth in the Wild, doi:10.2196/mental.3935, free):
  A/B-test features; study engagement predictors; surface professional-care
  resources; stand-alone safety-plan app (plan usage was 0.25%); precision
  medicine — "what works well for whom"; longitudinal engagement datasets.
- **Hallenbeck 2022** (v3.1, doi:10.2196/34744, free): same family — A/B
  testing, engagement predictors, care resources, safety-plan app,
  precision medicine.
- **Bröcker 2023** (meta, doi:10.1080/20008066.2023.2209469, free): more
  LMIC research; evaluate SUPPORTED (not just self-managed) versions;
  Android parity; cultural adaptation (US-veteran tools misfit elsewhere);
  longer follow-ups; larger samples.
- **Kuhn 2017** (RCT, doi:10.1037/ccp0000163, PAYWALLED — abstract only):
  engagement↔dose link; clinical populations; longer periods; who-benefits
  predictors; clinician support add-on; active controls.
- **Possemato 2023** (clinician-supported, doi:10.1007/s11606-023-08130-6,
  free): users "do not use apps enough on their own and need guidance";
  clinicians teach when/how + human connection; dose-response; component
  analysis; who-benefits predictors; service models for mHealth in care.
- **Van Stolk-Cooke 2023** (Family Coach, doi:10.2196/42053, free): simplify
  onboarding; light-touch psychoeducation over skill-building for
  time-poor users; immediate per-tool feedback; granular usage data;
  Android version.
- **Rodriguez-Paras 2017** (usability, proceedings): user-centered design,
  pre/post-release testing, personalization options, visual design,
  clearer technique instructions, treatment-integration design,
  confidentiality handling.
- **Wickersham 2019** (5-RCT review, PMC6463234, free): powered samples,
  clinician-administered measures, active controls, adverse-effects
  monitoring (one study: app use worsened social QoL), use predictors,
  longer follow-ups, UX optimisation.
- **Bröcker 2024** (South Africa counsellor-supported RCT,
  doi:10.1017/gmh.2023.92, free): same-community counsellors beat language
  barriers; culturally/linguistically adapt; take it to communities;
  larger samples; delayed effects need long follow-up.
- **Grant 2025** (EMDR app pilot, doi:10.34133/jemdr.0003, free):
  clinician support calls; motivational features; shorten to <30 days
  (retention); monitor adverse responses; establish minimum dose; hybrid
  app+therapy model; separate PTSD vs C-PTSD samples.
- **VA app family:** PE Coach (RCT recruiting NCT04959695), CPT Coach
  (few trials), STAIR Coach (RCT planned NCT06689787, EMA + passive
  sensing), Family Coach v2 (Android now).

## Top repeated suggestions (by paper count)
1. Add clinician/human support — 6 papers. OUR GAP (biggest): we're
   offline self-managed. Answer: therapist-export + Find Support +
   optional human bridge; never fake it in-app.
2. Engagement/onboarding fixes — 5. We answer with zero-permission,
   no-account, seeded profile, 15s bare path.
3. Track engagement + find the "dose" — 5. We answer with outcome-tracked
   reranking + Episode analytics (already built).
4. Personalization — 4. We answer with reranking + dissociation routing.
5. Cultural adaptation — 4. We answer with India directory + regional
   routing (formal adaptation study = future work).
6. Clinical-care integration — 4. OUR GAP: shareable clinician report +
   warm-handoff directory (Tier1).
7. Active controls / bigger RCTs / longer follow-up / CAPS measures —
   research design, for our future validation study, not the app.
8. Safety/adverse monitoring — 3. We answer with safety filter + WORSE
   stop + (Tier1) systematic adverse-event logging.
