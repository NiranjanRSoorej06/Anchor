# Anchor — Symptom-to-Exercise Evidence Table

*Every row maps a current symptom state to a technique, with the actual clinical proof behind it and a working link to the source. Rows are labeled by evidence strength — this table does not claim a technique is proven when it isn't, and several rows exist specifically to record what should NOT be used or what remains unproven.*

## Notes on using this table

- **Dissociation** and **Frozen/Not-sure/Overwhelmed** rows describe evidence *cautions* or *labeled gaps* — not proven techniques. Presenting them with the same confidence as the hyperarousal/flashback rows would overclaim.
- **Grounding** and **self-calming** are validated as *components of* multi-module clinical programs, or as *guideline-recommended categories* — not as isolated 60–90 second techniques independently tested. Keep that distinction visible if this table is shown to anyone who might check the sources.
- **Nightmare-related rows are included for completeness and honesty**, not because they belong in the live app. Imagery rehearsal therapy is real and evidenced, but it is a multi-session clinical treatment requiring guided practice over weeks — it does not fit an acute, seconds-to-minutes distress-episode format. Including it here documents that the evidence was checked and knowingly excluded, rather than silently omitted.
- Rows marked "do not rely on X alone" or "no advantage" are included deliberately — a defensible evidence table should show what was tested and *ruled out*, not only what worked. This is what makes "traceable to evidence.md" a real claim rather than a curated highlight reel.
