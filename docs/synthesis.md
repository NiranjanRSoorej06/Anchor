# synthesis.md — Good vs Bad + Testable Hypotheses (2026-09-04)

> Maps complaints.md clusters A-H + PTSD_COACH_TEARDOWN.md gaps to what we must prove in demo.

## Good (keep from PTSD Coach)
- Free, no account, no ads — lowers stigma to try.
- PCL-5 + tracking graph — judges like measurable.
- 21 CBT tools (breathing, grounding, muscle relaxation) — evidence base.
- Customizable (own audio/photo/text), dark mode, peer stories.
- 1M+ downloads / 115 countries = validates demand.

## Bad (kill / fix)
- A Trust: 17 perms vs local-only claim, anon telemetry, not open-source, no HIPAA clarity.
- B One-size: combat language, VA locator, 988-Veterans only, English-only, zero CPTSD (affect, shame, relationships, dissociation).
- C Generic: google-able tips, 10-min audio unusable at work, predictable.
- D Nagging: forced PCL-5 repeats, crisis-line spam, broken journal, sound persists.
- E Buggy: stuck logo, crashes, Android layout broken, update broke open.
- F No bridge: expects human/coach/doctor, gets directory dump.
- G Context-blind: assumes money/time/quiet.
- H Unsafe: panic/anger after use, solo-delving with no guardrails.

## Testable hypotheses for brainstorm (are we solving this?)
1. H1 Inclusive: Can a civilian / CPTSD / non-US user complete onboarding without combat language? Test: trauma-type picker -> tailored plan, ITQ-lite not just PCL-5.
2. H2 Privacy: Can we run core loop with zero perms + explain each optional perm? Test: offline-first, privacy dashboard, open-source claim.
3. H3 Context-smart: Can user de-escalate in <60s at work, silent, no money/space? Test: work-safe mode (text-only, no audio), 1-tap grounding.
4. H4 Adaptive not nagging: Does app reduce quiz/crisis spam while staying safe? Test: ask PCL-5 max 1x, crisis only on risk + gentle handoff, journal always writable, audio stops on exit.
5. H5 Human bridge: Can user reach human in 2 taps when wanted? Test: trusted contact, therapist matcher, warm handoff script (not just helpline list).
6. H6 Reliable: Does it load <1s offline, Android-safe? Test: PWA/offline-first, no login wall.
7. H7 Safe: Does distress (SUDS 0-10) go down after tool or offer switch + exit? Test: pre/post SUDS, exit button always visible, no solo trauma dive.
